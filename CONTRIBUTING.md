## Development Workflow

1. Create a feature branch

```bash
git checkout -b feature/my-feature
```

2. Make focused commits with clear commit messages

Examples:

```text
feat: add new functions etc
fix: correct some bug
docs: update some doc
```

3. Run tests before submitting changes

4. Submit a merge request with:
- summary of changes
- testing performed
- related issues if applicable

## Coding Guidelines

- Follow existing project coding style
- Keep changes small and maintainable
- Add documentation for public APIs
- Do not include confidential or third-party restricted code

## Questions

For questions or discussions, contact the repository maintainers.
